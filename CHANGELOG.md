# Changelog

All notable changes to the Tamo Images platform will be documented here. Versions follow Semantic Versioning and the service tag conventions in `docs/REPOSITORY_GOVERNANCE.md`.

## Unreleased

#### Added

- Polyglot monorepo orchestration, CI foundations, architecture contracts, and NDPR backend engineering standard.

### Identity service

#### Added

- Configuration validation, PostgreSQL migrations, Redis rate limiting, Kafka publishing, health endpoints, problem details, OpenAPI export, and authentication foundations.

- Configuration validation, HTTP foundations, PostgreSQL migrations, Redis, Kafka and MinIO adapters, dependency integration tests, and bounded worker pool.

### Web application

#### Added

- Next.js foundation and typed identity and media API adapters.

### Infrastructure

#### Added

- Pinned PostgreSQL, Redis, Kafka and MinIO Compose services with health checks and bootstrap jobs.
